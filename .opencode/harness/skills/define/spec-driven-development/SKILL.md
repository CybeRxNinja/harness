# Spec-Driven Development (vendored subset, MIT: addyosmani/agent-skills)
## When to Use
New project/feature/significant change.
## Procedure
1. Objectives + non-goals. 2. Commands/structure/style. 3. Testing + boundaries.
## Rationalizations
- "I'll spec later" -> No: spec before code.
## Verification
PRD file exists with acceptance criteria per item.
