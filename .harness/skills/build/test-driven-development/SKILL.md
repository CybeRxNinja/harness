# TDD (vendored subset, MIT: addyosmani/agent-skills)
## When to Use
Logic, bugs, behavior changes.
## Procedure
1. Failing test first. 2. Minimal code. 3. Refactor. Pyramid 80/15/5.
## Rationalizations
- "I'll add tests later" -> Rejected: tests are proof, not later.
## Verification
Failing->passing output pasted; no skipped gates.
